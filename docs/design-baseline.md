# 当前设计基准：V0.10 双端原型

2026-11-03 用户提供 V0.10 双端包。桌面三个 HTML 与 ZIP 内同名文件的 SHA256 全部一致；本任务输出目录 design-reference/v0.10 已保留原文件、原包与校验记录。

控制端 random_controller_v0_10.html 是小程序 UI、普通工具、活动配置和手机控制的对照来源；大屏端 random_display_v0_10.html 是 Web 投影舞台的对照来源；random_v0_10_dual.html 仅为总入口。V0.10 保留 V0.9.6 首页设计，新增独立控制端/大屏关系，因此替代之前仅以 V0.9.6 为对照的约定。

目前正式工程的云端身份校验、事务、加密抽取、请求去重及服务端时间校验继续保留。原型同步代码不直接替换正式云端；原型内的功能文案也不意味着工程已完成对应功能。

仍需逐项迁移验收：

- 普通工具的完整视觉、转盘盘面及结果流程；当前工具页是初步功能迁移。
- 活动配置的完整布局、奖项编辑、奖品图片/图标、横版 Logo 和主题。
- 开奖台的状态按钮、动画、音效、结果卡片及右侧进度。
- 独立 Web 大屏的完整视觉、只读授权、云端同步及断线恢复。
- 手机真机与电脑大屏联调、隐私备案和正式发布。

后续界面变更以这份原型为准，并明确记录平台限制造成的必要调整；不得用新写的简化界面代替原设计后宣称视觉迁移完成。
