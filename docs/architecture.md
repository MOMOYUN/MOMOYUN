# V0.11 工程边界
来源：主会话及 Notion 产品页（2026-11-01）。本版建立 uni-app/Vue3/TS 小程序、Vue/Vite 大屏和独立 lottery-core。没有原型附件，未声称完成视觉逐像素迁移。

核心：createEvent 克隆规则；startDraw → stopDraw → nextDraw；按奖项独立权重逐次抽取，每次移除中奖者；跨批次、跨奖项排除。滚动动画不参与计算。随机源由服务端注入，生产必须使用加密随机源，不回退 Math.random。指纹或日志不代表公证。

云端下一阶段：以云函数身份读取 OPENID，禁止信任客户端 owner；活动文档默认禁止客户端读写。start/stop/next 必须在事务内验证 owner、expectedVersion 和 phase，再更新结果与版本。请求重试返回相同结果，禁止重新抽取。大屏需独立只读授权，仅暴露必要展示数据，禁止暴露完整名单和权重。尚未实现这些云功能，前端不会伪装连接成功。

TDesign：保留接入计划；本轮先使用 uni 原生组件，需实际验证原生小程序组件的 npm 构建与路径映射后接入。

cloudfunctions/event/service.ts 已实现与存储无关的所有者校验、版本冲突拦截、请求去重与状态更新。Repository 仍是接口，需对接真实 CloudBase 事务；调用方身份必须由云函数读取，不接受前端传入的 owner。请求响应快照缓存目前适合小场次测试，生产需改为独立请求集合与有界保留，避免文档膨胀。当前没有可直接部署的云函数入口。
