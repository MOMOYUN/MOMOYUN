# V0.11 云端活动闭环

uni-app/Vue3/TS 小程序调用 event 云函数；网页大屏仍为静态骨架。规则由 lottery-core 独立实现，页面滚动不参与计算。

event 从 wx-server-sdk 获取 OPENID，忽略客户端身份字段。创建请求以 OPENID 与 requestId 的 SHA256 作为文档 ID，在事务中校验规则指纹，使重试不会创建第二场活动。start/stop/next 在真实数据库事务中验证所有者、版本和当前阶段。服务端 randomBytes 提供抽取随机源，跨批次和跨奖项排除中奖者。

仅缓存最近一次请求的原始响应。该请求重试返回原响应，缓存淘汰后的旧请求被版本号拒绝，避免重新抽取及响应快照无限膨胀。每次提交覆盖整个活动文档以清除旧缓存。

lottery_events 集合由云函数创建。当前环境已验证客户端直接读写被拒绝。未建立公开 HTTP 入口；网页大屏必须另加只读授权和脱敏投影，不能直接开放此集合。

本版控制页支持文本名单、全奖项通用名单权重、多奖项/多批次、Emoji、手动停止、云端结果与最近活动恢复。核心支持按奖项独立权重，但页面尚未提供独立编辑器。图片上传、倒计时/自动停止、活动列表、大屏同步和九种普通工具仍未完成。

部署环境的默认运行时是 Nodejs16.13，代码通过 JSON 快照避免使用 structuredClone；上线前需评估升级到环境支持的维护中运行时并重新验证。当前测试不等同公证、公平性第三方认证或正式上线验收。
